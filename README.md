# BPOM Dangerous Cosmetics Management System (SQLite CRUD)

A Terminal-based Python application integrated with SQLite database to manage records of hazardous cosmetics based on BPOM public warnings.

## Features
- **Create**: Add new hazardous cosmetics data.
- **Read**: Display product records in a formatted terminal table.
- **Update**: Modify safety details and warning letter numbers.
- **Delete**: Remove records using primary key ID.
- **Security**: Utilizes Parameterized Queries to prevent SQL Injection (SQLi) attacks.

## Technologies Used
- **Language**: Python 3
- **Database**: SQLite3
